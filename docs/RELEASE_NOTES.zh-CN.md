# db firmware 0.3.1 简体中文界面 · 第 1 版

基于原作者 [v0.3.1 beta Windows 发布版](https://github.com/azqeurio/om-c-firmware/releases/tag/dbv0.3.1beta)制作的第三方电脑工具界面汉化。适用于 Windows x64，下载 EXE 后直接运行，无需安装 Python。

## 改动

- 将原韩文界面替换为简体中文，保留 English 切换。
- 汉化相机／固件选择、功能说明、字体编辑控件、声音设置、安装指南、进度提示和确认弹窗。
- 使用微软雅黑显示中文，中文版单独保存语言偏好，首次运行默认中文。
- 保留原作者名称、程序版本号和赞助入口。

## 范围

这是电脑工具的界面汉化。“韩语语言包”仍然生成相机韩语菜单；相机的语言资源、韩文预览文本及固件输出语言不变。底层模块的原始诊断信息可能仍为韩文或英文。

只替换三个界面模块及启动入口。构建检查确认其余 807 个 Python 模块和 407 个归档文件与原版一致，包括固件生成模块、补丁数据、机型配置和相机语言资源。

## 验证

- 全部 23 个机型配置的离屏界面自测通过。
- 检查到的可见控件无残留韩文；相机菜单预览原文保留。
- 简体中文／英文切换通过。
- SD 卡清空确认框的默认和退出按钮均为“否”。
- 未执行固件下载、生成、SD 卡写入或真机刷写测试。界面测试通过不代表相机固件功能已经验证。
